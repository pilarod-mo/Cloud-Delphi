# Método Cloud Delphi ponderado

Conversión del BORRADOR_RAPIDO.tex a R Markdown. Abrir Cloud_Delphi.Rmd en RStudio y usar Knit, o ejecutar generar_paper.R desde esta carpeta. Mantener Referencias.bib junto al Rmd. Para PDF se necesita LaTeX (por ejemplo TinyTeX); para HTML no. El formato es de trabajo, no la clase Wiley. Los resultados de simulación son los comunicados en el manuscrito original, no se recalculan: falta el código de simulación. Los autores siguen pendientes.
